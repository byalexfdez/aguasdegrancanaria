<strong>¿Qué hacer?, ¿Cuánto ahorraríamos?</strong>

|  |  |  |
| --- | --- | --- |
| ![](/imagenes/svg/consejos_ahorro-01.svg) | Instala economizadores en grifos y duchas, así podrás ahorrar más de 30 litros al día por persona. |  |
| Dúchate en lugar de bañarte, y corta el agua mientras te enjabonas. Así podrás ahorrar un mínimo de 30 litros cada vez que te duchas. |  | ![](/imagenes/svg/consejos_ahorro-02.svg) |
| ![](/imagenes/svg/consejos_ahorro-03.svg) | Regula la boya de tu inodoro, o instala un sistema de ahorro de agua. Si dispones de pulsador, puedes cortar o disminuir la salida de agua, ahorrando entre 4 y 9 litros por descarga. |  |
| Cierra el grifo al cepillarte los dientes o al afeitarte, puedes estar derrochando casi 20 litros cada vez. |  | ![](/imagenes/svg/consejos_ahorro-04.svg) |
| ![](/imagenes/svg/consejos_ahorro-05.svg) | Tira el papel higiénico, compresas y demás a la papelera, no al inodoro, así ahorrarás más agua. |  |
| Repara las goteras que puedas tener en los grifos, piensa que si pierdes una gota por segundo, derrochas más de 30 litros al día. |  | ![](/imagenes/svg/consejos_ahorro-06.svg) |
| ![](/imagenes/svg/consejos_ahorro-07.svg) | Cierra el grifo cuando estés enjabonando la loza, y usa sólo el agua necesaria para quitar el jabón. Puedes ahorrarte hasta 10 litros. |  |
| Llena un recipiente para lavar la verdura y aprovecha el agua para regar tus plantas. Con esto te ahorras casi 10 litros. |  | ![](/imagenes/svg/consejos_ahorro-08.svg) |

<strong>AL LAVAR LA ROPA...</strong>

|  |  |  |
| --- | --- | --- |
| ![](/imagenes/svg/consejos_ahorro-09.svg) | Si llenas el tambor de la lavadora harás menos lavados. Ahorrarás hasta 100 litros de agua y entre 1 y 2 kWh con cada lavado que no hagas. |  |
| Puedes usar el agua de los aclarados en la limpieza de las aceras, terrazas, azoteas, escaleras, etc. Ahorrarás hasta 20 litros de agua. |  | ![](/imagenes/svg/consejos_ahorro-10.svg) |
| ![](/imagenes/svg/consejos_ahorro-11.svg) | Compra electrodomésticos de bajo consumo (Clase A o B) aunque te sean un poco más caros. Ahorrarás el 50% de agua y de energía y en poco tiempo recuperarás ese dinero. |  |

*Hay muchos sistemas de ahorro de agua, pero todos empiezan por ti. Con poco esfuerzo de tu parte, puedes ahorrar varios litros de agua cada día, y muchos al mes. Siguiendo nuestras recomendaciones tus facturas se reducirán y contribuirás a preservar el agua.*
